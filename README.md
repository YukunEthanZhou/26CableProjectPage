# Rod Simulation and Cable Manipulation

Research demonstration videos from an ongoing simulation and robotics project at UCLA.

Live page: https://yukunethanzhou.github.io/26CableProjectPage/

Static site, served by GitHub Pages from the `gh-pages` branch: one page per section sharing `site.css` /
`site.js`, plus `images/` and `videos/`. `index.html` = Home (news), `gs-enhancement.html` = Real2Sim › GS
Enhancement, `simulator.html`, `sim2real.html`; `gs-optimization.html` only redirects old links.

Every commit adds one short dated entry (newest first) to the news list on `index.html`.
